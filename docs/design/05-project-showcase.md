## 3. Project Grid Layout Recommendation

### Desktop (≥ 1024px)

```
Row 1:  [CNC Market ─────────────────] [SchemaFlow ─────────────────]
        (50% width)                     (50% width)

Row 2:  [Typing Test ────────────────] [RudraShield ────────────────]
        (50% width)                     (50% width)

Row 3:  [Todo App ───────────────────] [CLI Scanner ────────────────]
        (50% width)                     (50% width)
```

All cards are equal size in the grid. "Featured" status is indicated by a badge, not by a different card size. This prevents layout complexity and ensures a clean, balanced grid.

### Mobile (< 768px)

Single column. All cards stack vertically in the same order.
